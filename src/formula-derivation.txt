Given a tree with height "h", we want to display it using a terminal, where we
want to draw the tree top-down, row by row (from i = 0 to i = h - 1).

Let "d" be the number of digits of the largest key in the tree. When printing keys,
each key is padded on the left side with zeros to fill up exactly "d" space.

To make the result look good, we add an outer padding value before the first 
node (denoted p_i), and a skip value between two nodes (denoted s_i). Additionally,
the leaf level has a padding value of 0 and a skip value that is alternating from 1 to 3.

Note that the TREE_LEVEL_NODES method returns a list of elements on the specified level,
also including empty spaces. This means that if a level has 4 slots, but 1 is actually used,
the method will return a list of length 4, with 3 NIL elements, and one real key.

The algorithm is then the following:

FUNCTION TREE_PRINT
   correction_p = floor(d / 2) - 1
   correction_s = ceil(d / 2) - 2

   IF h > 1
      a = 0
      p = 0
   ELSE
      a = (d + 2) * pow(2, h - 2) - 3
      p = a - correction_p
   END IF
   s = 0

   // Traverse all non-leaf levels
   FOR i IN 0..(h-2)
      // Print padding
      print(REPEAT_CHAR(' ', p))

      // Print keys with skips
      FOR x in TREE_LEVEL_NODES(i)
         print(LEFT_PAD( KEY[x], d )) // KEY[NIL] is ''

         IF x IS NOT LAST
            print(REPEAT_CHAR(' ', s))
         END IF
      END FOR

      print('\n')

      a = (a - 3) / 2
      s = p - correction_s
      p = a - correction_p
   END FOR

   // Print leaf nodes with alternating skip of 1 and 3
   ...
END FUNCTION
